## Задача 1

Функция получает на вход целое число. Это номер дня в 2027 году.

Функция возвращает строку `"workday"` для рабочих дней (пн–пт), строку `"day off"` для выходных дней и значение `None`, если аргумент функции был некорректным.

Корректный аргумент должен иметь тип `int` и лежать в диапазоне от `1` до `365`.

**Примеры:**

**Дано:**
```python
get_day_type(1)
```

**Результат:**
```python
"day off"
```

**Дано:**
```python
get_day_type(5)
```

**Результат:**
```python
"workday"
```

**Дано:**
```python
get_day_type(400)
```

**Результат:**
```python
None
```

## Задача 2

Функция получает на вход произвольное количество строк и склеивает их в одну строку.

Опциональный **именованный** аргумент `sep` задаёт строку-разделитель между склеиваемыми строками. По умолчанию используется пробел.

Корректность типов аргументов в этой функции проверять не требуется.

**Дано:**
```python
join_strings("Hello", "world")
```

**Результат:**
```python
"Hello world"
```

**Дано:**
```python
join_strings("red", "green", "blue", sep=", ")
```

**Результат:**
```python
"red, green, blue"
```

**Дано:**
```python
join_strings("Python", "is", "awesome", sep="-")
```

**Результат:**
```python
"Python-is-awesome"
```

## Задача 3\*

Функция `reduce()` получает на вход два или более целых числа в виде позиционных аргументов и функцию обработки `action(x, y)` с двумя аргументами.

Функция применяет `action()` к первому и второму аргументу, затем к полученному результату и третьему аргументу, затем к новому результату и четвёртому аргументу и так далее.

Функция возвращает итоговый результат.

Корректность типов аргументов в этой функции проверять не требуется.

**Дано:**
```python
summa = reduce(1, 2, 3, action=lambda x, y: x + y)
print(summa)
```

**Результат:**
```python
6
```

**Дано:**
```python
minimum = reduce(
    1,
    2,
    3,
    0,
    action=lambda x, y: x if x < y else y
)
print(minimum)
```

**Результат:**
```python
0
```

**Дано:**
```python
product = reduce(
    2,
    3,
    4,
    action=lambda x, y: x * y
)
print(product)
```

**Результат:**
```python
24
```

## Задача 4\*

Напишите функцию `characterPrinter()`, которая возвращает другую функцию.

Возвращаемая функция должна принимать строку и число `n`, а затем выводить `n` символов из строки, начиная с того места, где она остановилась в предыдущем вызове.

Если строка заканчивается, функция должна начать вывод с начала строки.

**Пример использования:**

**Дано:**
```python
printer = characterPrinter()

printer("Hello world!", 3)
```

**Вывод:**
```python
Hel
```

**Дано:**
```python
printer("Hello world!", 4)
```

**Вывод:**
```python
lo w
```

**Дано:**
```python
printer("Hello world!", 4)
```

**Вывод:**
```python
orld
```

**Дано:**
```python
printer("Hello world!", 2)
```

**Вывод:**
```python
!H
```

Начинаем вывод с начала строки после достижения её конца.
